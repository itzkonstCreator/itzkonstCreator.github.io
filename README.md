# 1tzKonst Website

Официальный сайт разработчика ROBLOX проектов и скриптов.

## 📋 Описание

Этот репозиторий содержит исходный код официального сайта 1tzKonst — платформы для распространения ROBLOX скриптов, uncopylocked игр и других инструментов.

## 🚀 Проекты

### 🎮 Uncopylocked Games
Открытая коллекция анкопированных игр Roblox с возможностью скачивания и изучения механик.

### 🛠️ Scripts
Скрипты для ROBLOX (Solara). Легко копируй и используй в своих проектах.

### ⌨️ WPM Test
Инструмент для проверки скорости печати с режимом "одно слово за раунд".

## 📂 Структура

```
docs/
├── index.html          # Главная страница
├── styles.css          # Централизованные стили
├── uncopylocked.html   # Страница с uncopylocked играми
├── scripts.html        # Страница со скриптами
├── wpmtest.html        # Тест скорости печати
├── words.txt           # Список слов для WPM теста
└── itzkonsthub.lua     # Главный скрипт
```
